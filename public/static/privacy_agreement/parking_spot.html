我的车呢 隐私政策

生效日期：2026年5月21日

最后更新日期：2026年5月21日

欢迎您使用"我的车呢"应用程序（以下简称"本应用"）。我们深知个人信息对您的重要性，并将按照法律法规的要求，采取相应安全保护措施来保护您的个人信息。

在使用本应用前，请您仔细阅读并充分理解本隐私政策。一旦您开始使用本应用，即表示您已充分理解并同意本政策。

一、我们收集的个人信息

1. 位置信息

收集目的：用于定位您的停车位置，记录和显示停车地点，以及在地图上展示停车记录。

收集内容：

  • 经纬度坐标
  • 定位精度半径
  • 设备方向
  • 详细地址信息（国家、省份、城市、区县、街道）
  • 位置描述信息

收集方式：通过百度定位SDK获取，包括GPS定位、网络定位（基站定位和Wi-Fi定位）等方式。

使用场景：当您使用手动输入、语音记录、地图记录等功能记录停车位置时，以及使用探索功能查看停车记录时。

2. 语音信息

收集目的：用于语音录入车位信息，通过语音识别将您说出的车位位置转换为文字记录。

收集内容：

  • 语音录音数据

收集方式：通过设备麦克风录音，并经由讯飞语音听写SDK进行语音识别处理。

使用场景：当您使用"语音记录"功能录入车位信息时。

3. 图片信息

收集目的：用于拍照识别车位号，通过OCR技术从图片中识别车位编号。

收集内容：

  • 拍摄的车位照片

收集方式：通过设备摄像头拍照，并经由腾讯云OCR服务进行文字识别处理。

使用场景：当您使用"图片识别"功能录入车位信息时。

4. 设备信息

收集目的：用于辅助网络定位功能。

收集内容：

  • 网络状态信息
  • Wi-Fi状态信息
  • 运营商信息

收集方式：通过百度定位SDK在定位过程中自动获取。

四、信息的存储

1. 存储方式

本应用收集的所有个人信息均存储在您的设备本地，包括：

  • 停车记录数据：存储在本地数据库中
  • 位置缓存信息：存储在本地文件中
  • 应用设置信息：存储在本地文件中
  • 语音文件：存储在应用专属目录中
  • 图片文件：存储在应用专属目录中
本应用不设有自有远程服务器，不会将您的个人信息上传至我们的服务器。

2. 存储地域

所有本地数据均存储在您设备的内部存储中，不涉及跨境数据传输。

3. 存储期限

您的个人信息将在您使用本应用期间持续存储。当您删除停车记录或清除应用数据时，相关信息将被永久删除。当您卸载本应用时，所有本地数据将被清除。

五、信息的安全保护

我们采取以下措施来保护您的个人信息安全：

  1. 本应用所有数据均存储在设备本地，不进行远程传输和存储（第三方SDK服务除外）。
  2. 本应用使用Android系统提供的安全机制保护本地数据。
  3. 本应用不会在未获得您明确授权的情况下收集任何个人信息。
  4. 对于第三方SDK的数据处理，我们要求其严格遵守相关法律法规和隐私政策。

六、您的权利

1. 访问和更正

您可以在本应用中随时查看和编辑您的停车记录信息。

2. 删除

您可以通过以下方式删除您的个人信息：

  • 在停车记录列表中删除单条记录
  • 在设置中清除所有数据
  • 卸载本应用将清除所有本地数据

3. 权限管理

您可以在系统设置中随时开启或关闭本应用的各项权限：

  • 进入"设置" → "应用管理" → "我的车呢" → "权限管理"

4. 第三方SDK数据

对于第三方SDK收集的信息，您可以通过相应第三方提供的机制行使您的权利，或联系第三方直接处理。

七、未成年人保护

我们高度重视对未成年人个人信息的保护。如果您是未满14周岁的未成年人，请在监护人的陪同和指导下使用本应用，并在监护人明确同意后向我们提供个人信息。

如果我们发现在未获得监护人同意的情况下收集了未成年人的个人信息，我们将尽快删除相关信息。

八、隐私政策的变更

我们可能会适时对本隐私政策进行修订。当政策条款发生变更时，我们会在应用内以适当方式通知您。若您在隐私政策修订后继续使用本应用，即视为您同意受修订后的隐私政策约束。
